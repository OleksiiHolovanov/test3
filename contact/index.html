Prepare details before contacting Rabona support

Support can route a request faster when the message is complete and easy to verify.

👤

Account details

Use the registered mobile number or account email, but never send the account password or one-time code.

🧾

Transaction reference

For deposits or withdrawals, include date, method, amount and any transaction identifier visible in the cashier.

🎟️

Bonus name

For Rabona bonus issues, include the campaign name, opt-in time and the bet or deposit connected to the offer.

📱

Device information

For app issues, mention iOS or Android, browser or app version and the page where the error appears.

Rabona contact FAQ

These questions were expanded to match real support and branded search intent.

How do I contact Rabona about login problems?

Use the official support channel and provide the registered mobile number, device type and the exact error message. Do not send passwords or one-time verification codes.

What should I include in a payment request?

Include the transaction date, method, amount, status shown in the cashier and any reference number. Attach screenshots only if the official support form allows it.

Can support activate a Rabona bonus manually?

That depends on the live promotion terms. Provide the campaign name and explain whether the issue happened before or after deposit, opt-in or bet placement.

Where can app problems be reported?

Use support or the help centre from the official Rabona site or app. Mention whether the issue appears on iOS, Android, mobile browser or desktop.
